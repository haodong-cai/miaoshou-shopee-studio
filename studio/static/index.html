    🌐 开启梯子/代理导致妙手接口超时的解决方法

    妙手开放平台域名 openapi-erp.91miaoshou.com 是国内服务器，若代理开启全局或 Fake-IP 接管了国内域名，会导致请求读超时或触发 IP 白名单拦截。

    • 推荐做法（Clash / Mihomo / v2rayN）：在规则/分流或「绕过代理（Bypass）」列表中添加 DOMAIN-SUFFIX,91miaoshou.com,DIRECT（或 *.91miaoshou.com），让妙手流量直连，同时海外 AI 中转站仍可正常走代理。
    • 临时验证：关闭系统代理后，打开「⚙ 全局配置 → 🔑 妙手 ERP 密钥」点击「🧪 测试妙手接口连通性」，看到绿色成功提示即可正常拉取与回传。

    🔑 如何申请妙手 ERP 开放平台应用密钥（AppKey / AppSecret）

    1. 登录妙手 ERP：使用主账号登录妙手 ERP 后台。
    2. 进入开放平台：在后台菜单进入 「开放平台」→「创建应用」（如果看不到开放平台入口，请联系妙手官方客服开通开放平台开发者权限）。
    3. 填写应用信息并提交审核：填写应用名称（如“铺货草稿工作台”）、应用描述，并勾选所需业务权限（商品/采集箱、店铺列表、图片空间等），等待审核通过。
    4. 复制密钥：审核通过后在应用详情页获取两串密钥：
      • AppKey：公开应用标识，格式类似 ak_1234567890abcdef
      • AppSecret：应用签名密钥，格式类似 as_xxxxxxxxxxxxxxxx（请妥善保管，切勿外泄）
    5. 写入本工作台：点击本页右上角「立即去填入密钥」（或直接编辑项目根目录 .env 文件填入 MIAOSHOU_APP_KEY 和 MIAOSHOU_APP_SECRET），保存后无需重启立即生效，再点「🧪 测试妙手接口连通性」验证。
    6. 关于 IP 白名单（可选）：妙手后台 IP 白名单为账户级配置——不配置则允许任意 IP 访问；若已配置白名单，必须把你本机的当前公网出口 IP 加进去（开启梯子会改变出口 IP，容易触发 ipNotInWhitelist）。

    🛠 妙手接口常见错误码速查

    错误码常见原因处理方法
    networkError / 超时梯子/代理拦截国内域名或 DNS 异常将 91miaoshou.com 加入代理直连规则，或临时关闭系统代理后点测试连通性。
    appNotFoundAppKey 填错或应用未审核通过核对 ak_... 是否有多余空格，确认妙手开放平台应用已审核启用。
    signInvalidAppSecret 不正确重新复制 as_... 粘贴保存（注意区分大小写）。
    signExpired本机系统时间偏差超过 5 分钟在 Windows 设置中点击「立即同步」校准系统时钟。
    appNoPermission应用未授权该接口到妙手开放平台为该应用勾选采集箱/商品/图片空间接口权限。
    ipNotInWhitelist出口 IP 不在妙手白名单内清空妙手 IP 白名单，或将当前直连公网 IP 加入白名单。

    🌟 生图 API 与中转站配置指南（推荐中转站直接跑通）

    工作台支持 4 种做图引擎，你可以零费用先用本地 Pillow 跑通，也可以随时接入任意 OpenAI 兼容的 API 中转站（如 OneAPI / NewAPI / OpenRouter / 各类聚合中转站）：

    做图模式适用场景中转站配置要点
    1. 对话改图（中转站首选）
    openai_chat_img    		 按原图改白底、翻译图内中文、去水印、换场景、多角度出图 走标准 /chat/completions 多模态接口，绝大多数中转站都支持。
    • Base URL：https://你的中转站域名/v1
    • 常用模型名：gemini-2.5-flash-image、gemini-2.5-flash-image-preview、gpt-4o-image（以你中转站后台列表为准）
    • API Key：填写中转站生成的 sk-... 令牌
    2. OpenAI 图片编辑接口
    openai_edit    		 官方 OpenAI 或支持 /images/edits 的中转站 程序自动将原图转 PNG 并 multipart 上传到 {base_url}/images/edits。
    • Base URL：https://你的中转站域名/v1
    • 常用模型名：gpt-image-1
    3. 本地 Pillow 模板渲染
    local_pillow    		 零费用预览、纯白底居中、促销边框/角标、SKU 底部规格标签 无需任何 API Key，免费秒出图。注意：图内中文翻译、去除水印、换生活场景需切换到上方 AI 模式。
    4. 自定义 HTTP 图片接口
    custom_http    		 自建 ComfyUI / Python 生图网关 / 私有脚本 POST JSON（含 prompt、image_url、image_base64、options），响应支持直接返回图片流或 JSON {"url": "..."} / {"image_base64": "..."}。

    ☁ 重要：AI 生图 / 本地图如何回传到妙手采集箱？

    • 情况 A（最省事）：你的中转站返回的是公网图片 URL（例如 https://...png）——同步回妙手时程序会自动调用妙手「图片空间 URL 上传接口」转存并替换主图，无需额外配图床！
    • 情况 B（中转站返回 Base64 或使用本地 Pillow 图）：图片保存在本机 out/drafts/images/，妙手服务器无法直接访问 127.0.0.1。你有两种方式回传妙手：
      1. 在「图片引擎与中转站」填写自定义图床上传接口（接收 multipart file 返回 {"url":"https://..."}）；
      2. 或用 Cloudflare Tunnel / ngrok 暴露本机 18765 端口，把公网域名填入本机公网穿透地址（如 https://xxx.trycloudflare.com），程序会自动拼接可被妙手拉取的图片链接。
